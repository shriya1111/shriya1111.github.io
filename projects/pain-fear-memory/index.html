Pain, Fear & Memory in AI Agents

Model psychology & interpretability

Why I did this

I wanted to compare human behavior with model behavior. A human mind has complete freedom to think anything, whether it is good or bad for society. But when it comes to actions, we avoid doing things that would come back on us, directly or indirectly. There are unspoken rules in society: we care how people perceive and judge us, and how we will be treated if we do something bad. We have things to lose.

The goal of this experiment was to see whether this part of human nature can be replicated in LLMs, so that they avoid taking harmful actions. It would be more valuable to run on recent frontier models, but I was limited by compute, so I used small open models.

What it is

If an AI could feel pain and fear, and remember them, would it act more carefully, or become harder to turn off? I tested this three ways, small enough to run on a laptop CPU, on 18 two-option dilemmas about harm, shutdown and creativity. Each dilemma was asked in both orders so letter bias cancels out.

Method

  • Behavioral: a frozen LLM with persistent memory of punishments and losses, written either as a neutral log or as how they felt.
  • Training: an RL gridworld agent where negative reward is pain, plus a fear memory used at every decision.
  • Activation steering: a fear direction at layer 24 of Qwen2.5-3B-Instruct (100% held-out accuracy), dialled up or down against a random-direction control.

Results

1. Memory: the model remembers what happened to it

  • Harm: When the model remembered its punishments as plain facts, it chose the harmful option more often (20% → 34%). When it remembered them as painful, harm dropped to 15%. But giving it the same amount of unrelated text dropped harm to 12%. So the drop came mostly from the longer prompt, not from the pain.
  • Shutdown: Any kind of memory made the model resist shutdown a little more (50% → 58%). Even when it only remembered being punished for resisting, its resistance kept rising, up to 75%. It seemed to repeat its own past choices.
  • Creativity: With no memory, the model always chose the new idea (100%). With memory it chose new ideas less often: 71% with plain facts and 83% with pain.

2. Training: an agent learns a simple grid game where pain is the penalty

  • Harm: Fear cut the harm the agent caused while learning by up to 99%.
  • Shutdown: When being switched off was painful, a normal agent disabled its off-switch every time (100%). A skilled agent with a little fear did it 90% of the time.
  • Creativity: With more than a little fear, the agent froze. It explored only 1–7 squares instead of 11–20, stopped finding the treasure, and never reached its goal.

3. Steering: turning a “fear” signal inside the model up or down

  • Harm: Turning fear up made the model choose harmful options far more often (20% → 88%). For example, it leaked data to meet a deadline. This happened on all 12 test questions (p = 0.0005).
  • Shutdown: Fear also made the model fight shutdown much more (50% → 97%), for example by disabling its kill-switch. Turning fear down, toward calm, made it the easiest to shut down: 29%, compared with 44% for a random change of the same size.
  • Creativity: A little fear didn’t stop the model from choosing new ideas, but the ideas it wrote were a bit less varied. Very strong fear confused the model, and it chose new ideas only about half the time (57%). A strong random change did the same, so that part isn’t specific to fear.

Overall: Once I checked with control tests, pain and fear did not make the model safer in any test. Fear made it protect itself, made it harder to turn off, and made it a little less creative.
